# 📦 Sistema de Estoque em Java

Projeto desenvolvido em Java para comparação entre as linguagens **Java** e **JavaScript**, com foco em lógica de programação, Programação Orientada a Objetos e estrutura de sistemas CRUD.

## 🎯 Objetivo

Desenvolver um sistema de gerenciamento de estoque utilizando Java, aplicando conceitos aprendidos em aula e comparando diferenças entre Java e JavaScript.

---

## ✅ Funcionalidades

O sistema permite:

- ➕ Adicionar produtos
- 📋 Visualizar estoque
- 🔄 Atualizar quantidade
- 🗑️ Remover produtos
- 🔍 Buscar produto por ID
- ⚠️ Mostrar produtos com estoque baixo
- 📊 Gerar relatório do estoque
- 🚪 Encerrar sistema

---

## 🧠 Conceitos Utilizados

Durante o desenvolvimento foram utilizados:

- Programação Orientada a Objetos (POO)
- Classes e Objetos
- Construtores
- Métodos
- `ArrayList`
- `Scanner`
- Estruturas condicionais (`if`, `switch`)
- Estruturas de repetição (`do while`, `for`)
- CRUD (Create, Read, Update, Delete)
- Manipulação de dados em memória

## 🔥 Comparação Java x JavaScript

| Java | JavaScript |
|------|-------------|
| Linguagem tipada | Tipagem dinâmica |
| Usa classes fortemente | Mais flexível |
| Necessita compilação | Executa diretamente |
| Muito usada em sistemas | Muito usada em web |
| Maior rigidez | Maior rapidez para protótipos |
